# 暇つぶし集（PWA版）— ナンプレ・マインスイーパー・ナンバーリンク・ドミノ倒し・光の回路

iPhone のホーム画面に追加して、オフラインで遊べるミニゲーム集です。
問題・盤面は端末内で毎回自動生成し、途中経過は localStorage に保存します。

## ファイル構成

## PC で試す

```bash
cd numpre
python3 -m http.server 8000
```
ブラウザで http://localhost:8000 を開く（数字キー・矢印キー・Backspace・m でメモ切替・Ctrl+Z で戻す）。

## iPhone に入れる（GitHub Pages の例）

Service Worker は **HTTPS** でないと動かないので、無料の静的ホスティングに置きます。

1. GitHub で新しいリポジトリを作り、このフォルダの中身をアップロード
2. リポジトリの Settings → Pages → Branch を `main` / `/(root)` にして保存
3. 数分後に出る `https://ユーザー名.github.io/リポジトリ名/` を iPhone の Safari で開く
4. 共有ボタン →「ホーム画面に追加」
5. 一度起動すればキャッシュされるので、以降は機内モードでも起動できる

## 更新するとき

ファイルを変更したら `sw.js` の `CACHE = 'numpre-v1'` を `v2`, `v3`… と上げてからアップロードします。
上げないと iPhone 側は古いキャッシュを使い続けます。

## 保存されるデータ（localStorage）

- `numpre-save-v1`：問題・正解・現在の盤面・メモ・経過時間・ミス数・Undo 履歴
- `numpre-stats-v1`：難易度ごとのクリア回数とベストタイム

## 難易度

`app.js` の `DIFFICULTY` で残すヒント数を指定しています（かんたん40／ふつう34／むずかしい28／超むずかしい24）。
解が1つに定まらなくなるマスは消さないので、超むずかしいは24〜28程度に落ち着きます。

**エクストリーム**は「どのヒントを1つ消しても解が1つに定まらなくなる」極小問題です。
1.5秒の間に極小問題を何十問も作り、ヒントが最も少ないもの（同数なら解くのに探索が多く必要なもの）を出題します。ヒントは21〜23個程度になります。
生成は `worker.js`（Web Worker）で別スレッドで行うので、その間も画面は固まりません。
時間を変えたいときは `app.js` の `extreme.budget`（ミリ秒）を調整してください。

## マインスイーパー

| 難易度 | 盤面 | 地雷 |
|---|---|---|
| 入門 | 8×8 | 8 |
| 初級 | 9×9 | 12 |
| 中級 | 10×14 | 25 |
| 上級 | 12×18 | 45 |
| 鬼 | 12×20 | 60 |

- 最初のタップで盤面を生成。タップしたマスと周囲8マスには地雷を置かない
- 生成した盤面をソルバーで解き、**推測なしで全部開けられる盤面だけ**を出題する
  （基本ルール → 境界マスの組み合わせ全列挙 → 残り地雷数、の順で判定）
- 操作：タップで開く／長押しまたは「旗」モードで旗／数字タップで周りをまとめて開く
- 保存：`mines-save-v1`（途中経過）、`mines-stats-v1`（難易度ごとのベスト・勝率）
- 難易度は `mines.js` の `LEVELS` で変更できる

## ナンバーリンク

| 難易度 | 盤面 | 数字 |
|---|---|---|
| 入門 | 5×5 | 5前後 |
| 初級 | 6×6 | 6前後 |
| 中級 | 7×7 | 7前後 |
| 上級 | 8×8 | 8前後 |
| 鬼 | 9×9 | 9前後 |

- ルール：同じ数字同士を線でつなぎ、線は交差・分岐しない。すべてのマスを埋める
- 生成：全マスを1マスの線から始め、隣り合う線の端同士をランダムにつないで盤面を分割 → 各線の両端を数字にする
- 一意性：ソルバーで解の個数を数え（2個見つかった時点で打ち切り）、**解が1通りの問題だけ**を出題する。
  ソルバーは行き止まりマス・孤立した空き領域・ゴールへ届かない線を検出して枝刈りする
- 正解判定は保存した答えとの比較ではなく、ルールを満たしているかで判定
- 操作：数字からなぞって線を引く／線の途中からなぞると引き直し／他の線を横切るとその線は切れる
- 保存：`link-save-v1`（途中経過）、`link-stats-v1`（難易度ごとのベスト・クリア回数。ヒント使用時はベスト対象外）

## 配置の調整（全ゲーム共通）

動画や配信を小窓（ピクチャ・イン・ピクチャ）で見ながら遊べるように、ゲーム画面全体を動かせます。

- 各ゲームのヘッダー右端の ✥ ボタンで調整モードに入る
- ドラッグで移動、2本指のピンチまたはスライダーでサイズ変更（50〜100%）
- 「上へ」「中央」「下へ」で上下に寄せる、「元に戻す」で初期位置
- 設定はゲームごとに `layout-v1` へ保存（盤面の形がゲームごとに違うため）
- 画面外へ行きすぎないよう、最低 80px は画面内に残る

## ドミノ倒し（オリジナル）

| 難易度 | 盤面 | 穴 |
|---|---|---|
| 入門 | 4×4 | 0 |
| 初級 | 5×5 | 1 |
| 中級 | 6×6 | 2 |
| 上級 | 7×7 | 3 |
| 鬼 | 8×8 | 6 |

- ルール：ドミノは矢印の向きに倒れ、倒れた先のドミノも連鎖して倒れる。「倒す！」で全部倒れるように向きをそろえる
- 盤の外・穴・倒れたドミノに向かうと連鎖が止まり、止まった場所が赤く光る。ドミノは起き上がり、もう一度挑戦できる
- ★評価：1回目で成功 ★3、3回目まで ★2、それ以降 ★1（ヒントを使うと最大 ★2）
- 全部倒れると、倒れたドミノが虹色の帯になる。効果音は初期設定 OFF（動画を見ながら遊ぶため）
- 仕組み：全部倒れる並べ方 = スタートから全マスを1回ずつ通る道（ハミルトン路）
- 生成：ランダムなハミルトン路を作る → 別解と食い違うマスに🔒（向き固定）を足していき、答えが1通りになったら、
  外しても1通りのままの🔒を外して減らす
- ソルバー：つながっていない空きマスや、行き止まりが2つ以上ある状態を枝刈りして、答えの数を数える
- 正しさの確認：小さい盤面 300 問で総当たりと答えの数が一致。生成した問題は答えが1通りで、答えどおりなら全部倒れる
- 保存：`domino-save-v1`（途中経過）、`domino-stats-v1`（ベスト・★3回数・クリア回数）

## 光の回路（オリジナル）

| 難易度 | 盤面 | 内容 |
|---|---|---|
| 入門 | 5×5 | 鏡だけ |
| 初級 | 6×6 | 鏡＋壁 |
| 中級 | 6×6 | ＋ハーフミラー（光が2つに分かれる） |
| 上級 | 7×7 | ＋赤と青の2色の光 |
| 鬼 | 8×8 | 2色・ハーフミラー2枚・ダミーの鏡多め |

- ルール：鏡をタップして ／ と ＼ を切り替え、全部の宝石に光を当てる。2色の面では、宝石の色と「ちょうど同じ色」の光が必要（紫 = 赤＋青）
- 光は毎回たどり直して表示。新しく光った宝石は弾み、余計な色が当たった宝石は赤い点線になる
- 完成すると光の流れが速くなり、宝石から光の輪が広がる
- ★評価：目安の手数（初期状態から直す必要がある鏡の数）以内で ★3、+3手まで ★2（ヒントを使うと最大 ★2）
- 生成：光源から光の道をたどり、曲がる地点に鏡を置く → 光が通らないマスにダミーの鏡と壁 → 光が通るマスから宝石を選ぶ
- 一意性：ソルバーは「光が当たった鏡だけ」を順に決めていく（当たらない鏡の向きは答えに関係しない）。
  別解があれば、別解と光り方が違うマスに宝石（または壁）を足して、答えが1通りになるまで繰り返す
- 正しさの確認：小さい盤面 400 問で、全部の鏡の向きを試す総当たりと答えの数が一致
- 保存：`light-save-v1`（途中経過）、`light-stats-v1`（ベスト・★3回数・クリア回数）
